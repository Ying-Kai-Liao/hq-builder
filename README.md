# builder

Builds and maintains hq agents. Use to create a new specialist, change what an agent can do, give it tools or skills, or audit an agent's context cost. Knows the repo's conventions and keeps each agent lean.

An agent for [hq](https://github.com/Ying-Kai-Liao/hq): a specialist that runs in Claude Code with its own memory,
skills and tools, on your own Mac.

```
hq install Ying-Kai-Liao/hq-builder
```

`hq install` shows what it may do on your Mac (permissions, tools, services) before keeping it. Its memory and data
stay yours; updating it (`hq update builder`) never touches them.
